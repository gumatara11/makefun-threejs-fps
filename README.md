EMBERLINE is a round-based tactical FPS in three.js: plant or defuse the bomb on a bright anime city map, or eliminate the other team, in a first-to-8 5v5 match with chibi robot operators, a buy economy, and five weapons.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
